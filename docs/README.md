# Documentation Architecture

This repository documentation is organized into focused sections. Each file is designed to help a reader quickly find the information they need.

## Docs structure

- `docs/getting_started.md`
  - Installation
  - Environment configuration
  - Running the service locally

- `docs/architecture.md`
  - System overview
  - Component breakdown
  - Data flow
  - Integration boundaries

- `docs/api.md`
  - REST API endpoints
  - Request / response samples
  - Error handling

- `docs/development.md`
  - Code organization
  - How to extend the pipeline
  - How to add tools or agents
  - Testing and migration workflow

## Documentation goals

- Make the architecture explicit for new contributors
- Document the knowledge ingestion flow and LLM graph flow separately
- Provide a single source of truth for env variables and deployment assumptions
- Align code modules with documentation sections
